# BooDate 👻

A fictional, comedy-first ghost dating website made for a useless-project competition.

## Run it in VS Code

1. Extract this ZIP.
2. Open the extracted `BooDate` folder in VS Code.
3. Open Terminal > New Terminal.
4. Run:
   npm install
5. Then:
   npm run dev
6. Open the localhost address Vite gives you.

## Included
- Home page
- Ghost discovery with 12 demo profiles
- Matching
- Ghost profile creation
- Chat demo
- Date booking + demo checkout
- Pricing/subscriptions
- Paranormal location scanner
- Responsive design
- Toast notifications and modal profiles

All names, prices, ghost counts, bookings and paranormal results are fictional/demo content. No real payments are processed.
